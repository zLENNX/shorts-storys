# Hintergrundmusik

Lege lizenzfreie Tracks (MP3/WAV/M4A/OGG) in die Ordner nach Stimmung.
Claude wählt pro Serie eine Stimmung, die App nimmt zufällig einen Track daraus und legt ihn leise
unter die Stimme (Lautstärke: `MUSIC_VOLUME` in `.env`).

| Ordner | Wofür | Suchbegriffe auf Pixabay Music |
|---|---|---|
| `music/spannung/` | Mystery, True Crime | „suspense“, „tension“, „mystery ambient“ |
| `music/horror/` | Horror, Creepy | „dark ambient“, „horror drone“, „creepy“ |
| `music/traurig/` | Drama, tragische Ereignisse | „sad piano“, „emotional“, „melancholy“ |
| `music/ruhig/` | Alltagsgeschichten | „lofi calm“, „soft background“ |
| `music/episch/` | Historische Ereignisse | „epic cinematic“, „documentary“ |

Quelle (kostenlos, ohne Namensnennung nutzbar): https://pixabay.com/music/
→ Track öffnen → **Download**. 2–4 Tracks pro Ordner reichen.

Tipp: Lieber Tracks **ohne Gesang** und mit gleichmäßiger Lautstärke nehmen, damit die Stimme verständlich bleibt.
Wenn ein Ordner leer ist, nimmt die App einen Track aus einem anderen Ordner; gibt es gar keine Musik, bleibt das Video ohne Musik.
